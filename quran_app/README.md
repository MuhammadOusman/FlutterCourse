# 📖 Quran App — Flutter UI Practice

A beginner-friendly **Flutter Quran app** that displays a list of Surahs (Chapters) from the Holy Quran. This project focuses on **UI design, list handling, and basic navigation**.

---

## 🌟 Features

- 📜 Displays Surah list from static/local data
- 🧭 Clean navigation structure
- 📱 Designed for responsiveness and readability
- 💡 Great as a starter for more advanced Islamic apps

---

## 🧰 Tech Stack

| Layer     | Technology   |
|-----------|--------------|
| Frontend  | Flutter (Dart) |
| Data      | Static List (local JSON or array) |
| Widgets   | ListView, Card, Navigator |

## 🛠️ How to Run

1. Clone the main repo and navigate:

```bash
git clone https://github.com/MuhammadOusman/FlutterCourse.git
cd FlutterCourse/quran_app
```

2. Install packages:

```bash
flutter pub get
```

3. Run the app:

```bash
flutter run
```

> ✅ Works well on emulator or physical device.
