## 🛠️ How to Run a Project

1. Navigate into a project folder:

```bash
cd project_name
```

2. Get dependencies:

```bash
flutter pub get
```

3. Launch app:

```bash
flutter run
```

📱 Works best with Android/iOS emulators or physical devices.
