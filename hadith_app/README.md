# 📜 Hadith App — Flutter Islamic Quotes App

A beautifully designed mobile app that displays a curated list of **Islamic Ahadith**. Built using Flutter, this app serves as a peaceful and minimalist interface for spiritual reminders.

---

## 🌟 Features

- 🕌 List of authentic Hadiths (pre-loaded)
- 🧾 Scrollable and readable layout
- 🌓 Dark/Light mode friendly UI (if themed)
- ⚡ Fast and offline-ready
- 📱 Built with clean widgets & stateful logic

---

## 🧰 Tech Stack

| Layer     | Technology   |
|-----------|--------------|
| Frontend  | Flutter      |
| Data      | Static List (offline) |
| Widgets   | ListView, Card, Text |

## 🛠️ How to Run

1. Clone this specific project:

```bash
git clone https://github.com/MuhammadOusman/FlutterCourse.git
cd FlutterCourse/hadith_app
```

2. Get the dependencies:

```bash
flutter pub get
```

3. Run the app:

```bash
flutter run
```

✅ The app works on both Android Emulator & physical devices.
