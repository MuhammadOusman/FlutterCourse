# ✅ Todo App — Task Manager in Flutter

A clean and minimal **Todo List app** built with Flutter. This app allows users to add, complete, and track their daily tasks — built entirely using core Flutter widgets and local state management.

---

## 🌟 Features

- ➕ Add new tasks (voice and text)
- ☑️ Mark tasks as completed (checkbox)
- 🗑️ Remove completed tasks 
- 🧠 Simple state management (no external libs)
- 💡 Beginner-friendly structure

---

## 🧰 Tech Stack

| Layer     | Technology     |
|-----------|----------------|
| Frontend  | Flutter (Dart) |
| State     | Stateful Widgets |
| Data      | In-memory+ Hive |

## 🛠️ How to Run

1. Clone the repository and navigate:

```bash
git clone https://github.com/MuhammadOusman/FlutterCourse.git
cd FlutterCourse/todo_app
```

2. Get Flutter dependencies:

```bash
flutter pub get
```

3. Launch the app:

```bash
flutter run
```

> 🚀 You’re ready to build productivity tools in Flutter!
